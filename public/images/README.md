# Imagens

Coloque aqui a foto de capa do casal como `cover.jpg` (referenciada em
`src/config/wedding.ts` → `coverImage: "/images/cover.jpg"`).

Enquanto não houver imagem, o hero exibe um fundo neutro com sobreposição.

## Galeria (`ensaio/`)

As fotos do carrossel da página **Nossa História** — só as deitadas, já
redimensionadas para a web (lado maior 1800px). A capa (`cover.jpg`) é uma
foto em pé do mesmo ensaio. Veja "Fotos da galeria e capa" no README da
raiz antes de trocá-las.
